Google Contacts — What Savvo Reads

Only these fields are read from Google Contacts:

  • ✓ Name
  • ✓ Email address
  • ✓ Phone number
  • ✓ Company & job title

What Savvo does NOT do:

  • ✗ Never modifies your Google Contacts
  • ✗ Never deletes contacts from Google
  • ✗ Never shares contact data with third parties
  • ✗ Never syncs back — import is one-time only

Google Calendar — What Savvo Reads

Only these fields are read from calendar events:

  • ✓ Event title
  • ✓ Attendee names & emails
  • ✓ Event date & time

What Savvo does NOT do:

  • ✗ Never creates or modifies calendar events
  • ✗ Never reads event descriptions or attachments
  • ✗ Never accesses events you didn't attend
  • ✗ Never shares calendar data with third parties

Data Privacy & Security

How imported Google data is protected

  • ✓ Data stored in Supabase with Row-Level Security — each user can only see their own contacts
  • ✓ All API routes require authentication
  • ✓ HTTPS everywhere with HSTS preload
  • ✓ Users can delete all data via Settings → Delete Account
  • ✓ Users can export all data as CSV anytime
  • ✓ Privacy policy: savvo.app/privacy
  • ✓ Terms of service: savvo.app/terms

Summary

Savvo requests two read-only Google scopes

contacts.readonly

One-time import of contacts (name, email, company) into Savvo. Never writes back.

calendar.readonly

Reads 1:1 meeting attendees to auto-create contacts. Never modifies events.
